# Como contribuir

1. **Dúvidas e correções:** abra uma *issue* dizendo a nota e o trecho. Corrigir uma citação com a página da edição em papel é a contribuição mais útil.
2. **Mudanças nas notas:** crie um ramo `estudo/<tema>` a partir da `rascunho`, edite e abra um pull request para a `rascunho`.
3. **Regras das notas:**
   - Resumo é paráfrase; citação entre aspas, curta, com autor, obra e página (ou capítulo).
   - O que não foi conferido na fonte termina com *(conferir)*.
   - Leitura própria ou pergunta vem marcada como *(interpretação)* ou *(pergunta)*.
   - Link entre notas no formato `[[Nome da nota]]`.
4. **Publicar:** quando a `rascunho` estiver pronta, abra um pull request da `rascunho` para a `main`. Ao entrar, o site é atualizado sozinho.
